# 0008: A model swap is a release with its own gate

## Status
Accepted.

## Context
A smaller model is about 3 times cheaper per token, but makes more reading mistakes.

## Decision
A candidate model runs as a design on the same world and luck. It passes only if all three hold:
- it captures no more than 3 points less value than the sentinel;
- at least 85% of its cards matter;
- it uses no more than 1.25 times the people's minutes.

## Consequences
- On the development seeds the smaller model passed: 2.1 points below the sentinel, with 11.8 articles a week to the
  desk instead of 5.0.
- The saving is about €0.12 a week in tokens, against about 50 more desk minutes a week. Tokens are not where the
  cost is.
